# Games News

Portal de notícias sobre games feito com HTML, CSS e JavaScript puro.

As notícias são fictícias, inspiradas em lançamentos e eventos reais de setembro de 2026.

## Paleta

| Cor | Hex |
|---|---|
| Destaque | `#E63946` |
| Destaque escuro | `#B5222F` |
| Escuro | `#1D1D2B` |
| Texto secundário | `#5C5C70` |
| Fundo | `#F5F5F7` |
| Superfície | `#FFFFFF` |
| Borda | `#E2E2E8` |

## Fontes

- **Newsreader**: logotipo e títulos
- **Inter**: navegação, textos, metadados e botões

Ambas do [Google Fonts](https://fonts.google.com).
